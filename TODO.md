## 3. Prism: мультитрек HLS (master-плейлист) — для локального переключения дорожек
Сейчас Prism отдаёт медиа-плейлист с ОДНОЙ вшитой аудиодорожкой
(`segment/N.ts?audio=K`), а субтитры — отдельным эндпоинтом
`/api/media/{id}/subtitle/N.vtt`. Из такого вывода переключать аудио/субтитры на
плеере нельзя (в плейлисте нет `#EXT-X-MEDIA`-рендиций).

Нужно, чтобы Prism отдавал **HLS master-плейлист** с рендициями:
`#EXT-X-MEDIA:TYPE=AUDIO` (альтернативные аудио) и `TYPE=SUBTITLES` (WebVTT). Тогда
ExoPlayer в плеере сам показывает список дорожек и переключает их **локально, из
одного URL, без координатора**. Это предпосылка для команд `setAudio`/`setSubtitle`
(см. `Prism.Player.Android/TODO.md`, п.1). Нюанс: в WebVTT переводятся только
текстовые субтитры; графические (PGS/VOBSUB) — только прожигом (отдельная задача).
