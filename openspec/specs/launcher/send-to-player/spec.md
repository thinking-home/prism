# launcher/send-to-player Specification

## Purpose
Основной сценарий лаунчера: пользователь присылает видеофайл через «Отправить»,
лаунчер находит его в библиотеке хоста по содержимому и включает на выбранном
сетевом плеере.

## Requirements

### Requirement: Резолв присланного файла на хосте
Лаунчер SHALL вычислять отпечаток присланного файла и запрашивать хост
(`GET /api/resolve`), не отправляя путь файла на хост. Если хост не
настроен, файл не найден на диске, хост недоступен, файл не числится в
библиотеке хоста или файл не воспроизводим — лаунчер SHALL показывать
пользователю уведомление, объясняющее причину, и не продолжать сценарий.

#### Scenario: Хост не настроен
- **WHEN** адрес хоста в настройках пуст, и пользователю присылают файл
- **THEN** лаунчер показывает уведомление о том, что нужно задать адрес хоста, и не пытается связаться с хостом

#### Scenario: Присланный файл не существует
- **WHEN** путь, переданный лаунчеру, не существует на диске
- **THEN** лаунчер показывает уведомление «файл не найден» с этим путём

#### Scenario: Хост недоступен по сети
- **WHEN** хост не отвечает на запрос резолва
- **THEN** лаунчер показывает уведомление о недоступности хоста

#### Scenario: Файл не в раздаваемых папках хоста
- **WHEN** отпечаток файла не найден хостом (404 на `/api/resolve`)
- **THEN** лаунчер показывает уведомление с перечислением раздаваемых хостом папок (если хост доступен) либо общее сообщение, что хост не раздаёт этот файл

#### Scenario: Файл найден, но не воспроизводим
- **WHEN** хост резолвит файл, но помечает его невоспроизводимым
- **THEN** лаунчер показывает уведомление «нельзя воспроизвести» с названием файла и не предлагает выбор плеера

### Requirement: Выбор плеера для воспроизведения
После успешного резолва лаунчер SHALL получить список известных плееров
(из MQTT). Если плееров нет — лаунчер SHALL показать предупреждение и не
отправлять команду. Если плеер один — команда SHALL отправляться на него сразу,
без запроса подтверждения. Если плееров несколько — лаунчер SHALL показать
пользователю меню выбора плеера у курсора.

#### Scenario: Плееров в сети не найдено
- **WHEN** файл успешно зарезолвен, но список известных плееров пуст
- **THEN** лаунчер показывает предупреждение «плееры не найдены» и не отправляет команду

#### Scenario: В сети один плеер
- **WHEN** файл зарезолвен, и известен ровно один плеер
- **THEN** лаунчер сразу отправляет этому плееру команду воспроизведения без дополнительного выбора

#### Scenario: В сети несколько плееров
- **WHEN** файл зарезолвен, и известно несколько плееров
- **THEN** лаунчер показывает меню выбора плеера у курсора мыши

### Requirement: Отправка команды и уведомление о результате
Лаунчер SHALL публиковать команду воспроизведения выбранному плееру по MQTT с
абсолютным URL потока (базовый адрес хоста + относительный `streamUrl` из
резолва) и показывать уведомление об успехе или ошибке отправки.

#### Scenario: Команда успешно отправлена
- **WHEN** лаунчер публикует команду воспроизведения выбранному плееру
- **THEN** пользователь видит уведомление с названием файла и именем плеера

#### Scenario: Отправка команды завершилась ошибкой
- **WHEN** публикация команды в MQTT завершается ошибкой
- **THEN** пользователь видит уведомление с описанием ошибки
