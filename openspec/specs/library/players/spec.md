# library/players Specification

## Purpose
Библиотека знает, какие сетевые плееры Prism сейчас доступны, и умеет включить
на любом из них любой файл из агрегированного каталога — клиенты работают
только с её HTTP API, не зная о MQTT.

## Requirements

### Requirement: Обнаружение плееров по MQTT
Библиотека SHALL подписываться на MQTT-топики сведений и состояния плееров
(`prism/player/+/info`, `prism/player/+/state`) и поддерживать список известных
плееров с признаком «в сети» на основе свежести последнего полученного
сообщения.

#### Scenario: Плеер публикует состояние
- **WHEN** плеер публикует сообщение в свой топик состояния
- **THEN** библиотека добавляет или обновляет запись об этом плеере в своём списке

#### Scenario: От плеера долго нет сообщений
- **WHEN** от ранее известного плеера не приходило сообщений дольше окна свежести
- **THEN** список плееров показывает этот плеер не в сети

### Requirement: Список плееров
`GET /api/players` SHALL возвращать известные библиотеке плееры (id, имя,
признак «в сети», статус и позицию воспроизведения, если известны). Если MQTT
не настроен — ответ SHALL быть 503.

#### Scenario: MQTT не настроен
- **WHEN** в конфигурации библиотеки не задан адрес MQTT-брокера
- **THEN** `GET /api/players` отвечает 503

#### Scenario: Есть известные плееры
- **WHEN** MQTT настроен и библиотека видела сообщения от плееров
- **THEN** `GET /api/players` возвращает их список с признаком «в сети» для каждого

### Requirement: Включение файла на плеере
`POST /api/players/{id}/open` SHALL резолвить переданный id файла в
абсолютный URL потока адресно (через агрегированный каталог) и публиковать
команду воспроизведения в топик команд указанного плеера. Библиотека SHALL
отвечать 404, если плеер неизвестен или файл не найден ни на одном доступном
хосте, 400 — если найденный файл невоспроизводим, 503 — если брокер не
настроен или недоступен, и подтверждать публикацию (202), не дожидаясь
подтверждения от самого плеера.

#### Scenario: Успешное включение
- **WHEN** отправлен `POST /api/players/{id}/open` с id воспроизводимого файла и известным плеером
- **THEN** библиотека публикует команду воспроизведения в топик плеера и отвечает 202

#### Scenario: Неизвестный плеер
- **WHEN** id плеера в запросе не встречался библиотеке в MQTT
- **THEN** ответ 404

#### Scenario: Файл не найден ни на одном хосте
- **WHEN** переданный id файла не находится ни на одном доступном хосте
- **THEN** ответ 404

#### Scenario: Файл невоспроизводим
- **WHEN** переданный id файла найден, но не имеет потокового URL (не воспроизводим)
- **THEN** ответ 400

#### Scenario: Брокер недоступен
- **WHEN** MQTT настроен, но соединение с брокером сейчас разорвано
- **THEN** ответ 503
