## Purpose

Даёт пользователю для любого файла в библиотеке два действия прямо из списка
папки: посмотреть подробную информацию о файле и запустить его воспроизведение
на выбранном сетевом плеере, не выходя из приложения.

## ADDED Requirements

### Requirement: Просмотр информации о файле
Выбор действия «информация» для файла SHALL открывать шторку (bottom sheet) с
карточкой файла, полученной через `GET /api/media/{id}` (включая мета-поля
библиотеки, наложенные поверх полей хоста), не закрывая текущий список папки.

#### Scenario: Открытие шторки с информацией
- **WHEN** пользователь выбирает действие «информация» у файла
- **THEN** открывается шторка с данными карточки этого файла, текущая папка
  остаётся открытой под ней

#### Scenario: Файл недоступен при запросе информации
- **WHEN** запрос карточки файла возвращает 404 (файл сейчас недоступен ни на
  одном хосте)
- **THEN** приложение показывает сообщение о недоступности вместо содержимого
  шторки

### Requirement: Запуск файла на плеере
Выбор действия «включить на плеере» SHALL показывать пользователю список
плееров, известных библиотеке (`GET /api/players`), для выбора. После выбора
плеера приложение SHALL отправлять `POST /api/players/{id}/open` с id файла и
показывать пользователю результат: подтверждение при 202, причину ошибки при
404, 400 или 503.

#### Scenario: Выбор плеера и запуск
- **WHEN** пользователь выбирает действие «включить на плеере» и затем
  выбирает плеер из списка
- **THEN** приложение отправляет команду воспроизведения этому плееру и
  показывает подтверждение об успешной отправке

#### Scenario: Нет известных плееров
- **WHEN** список плееров из `GET /api/players` пуст
- **THEN** приложение сообщает, что плееры не найдены, и не предлагает выбор
  плеера

#### Scenario: MQTT не настроен в библиотеке
- **WHEN** `GET /api/players` отвечает 503
- **THEN** приложение сообщает о недоступности запуска на плеере вместо списка
  плееров

#### Scenario: Файл не воспроизводим
- **WHEN** `POST /api/players/{id}/open` отвечает 400 для выбранного файла и
  плеера
- **THEN** приложение показывает сообщение о том, что файл нельзя воспроизвести

### Requirement: Ограничение действия «включить на плеере» неиграбельными файлами
Приложение SHALL не предлагать действие «включить на плеере» для файла,
помеченного в каталоге как невоспроизводимый (`playable:false`) или
недоступный (`present:false`); действие «информация» SHALL при этом оставаться
доступным для такого файла.

#### Scenario: Невоспроизводимый файл
- **WHEN** файл в текущей папке имеет `playable:false`
- **THEN** для него доступно действие «информация», но не «включить на
  плеере»
