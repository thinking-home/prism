## Why

Проект Prism не имеет OpenSpec-спецификаций. Чтобы дальнейшие изменения
лаунчера (`Prism.Launcher`, Windows-приложение «Отправить видео на плеер»)
можно было предлагать и ревьюить через OpenSpec, нужна базовая спецификация,
фиксирующая уже реализованное поведение.

## What Changes

- Задокументировать текущее поведение `Prism.Launcher` как baseline-спецификации:
  без изменения кода и без изменения поведения — только формализация того, что
  уже работает.
- Лаунчер охватывает: фоновое приложение в трее с автозапуском и интеграцией
  «Отправить», и сценарий отправки файла на плеер (резолв через хост, выбор
  плеера, команда через MQTT).

## Capabilities

### New Capabilities
- `launcher/tray-app`: фоновый процесс в трее (значок отражает состояние
  подключения к MQTT-брокеру), single-instance через мьютекс и именованный
  канал (повторный запуск с файлом передаётся уже работающему экземпляру),
  автозапуск при входе в систему и пункт «Отправить» в проводнике Windows
  (`ShellIntegration`), настройки только на чтение из `appsettings.json` рядом
  с exe (адрес хоста, адрес MQTT-брокера), пункт меню «открыть файл настроек».
- `launcher/send-to-player`: обработка файла, присланного через «Отправить»:
  резолв файла на хосте по отпечатку (`GET /api/resolve`), сообщения об
  ошибках (хост не настроен/недоступен, файл не найден, файла нет в
  библиотеке хоста, файл невоспроизводим), получение списка плееров из MQTT
  (`Prism.Mqtt`/`PlayerRegistry`) — без плееров показывается предупреждение,
  один плеер получает команду сразу, несколько — выбор из контекстного меню у
  курсора, публикация команды `open` через MQTT и уведомление об результате.

### Modified Capabilities
- (нет — в репозитории ещё нет ни одной спецификации)

## Impact

- Затронутый код: `Prism.Launcher` — только описание существующего поведения,
  изменений в коде эта задача не предполагает.
- Специфицируется только лаунчер. Контракт `/api/resolve` хоста и протокол MQTT
  плееров (`Prism.Mqtt`) описываются отдельным изменением `spec-host` (для
  контрактов хоста); сама библиотека и её работа с MQTT — изменением
  `spec-library`. Здесь фиксируется только то, как лаунчер их использует.
