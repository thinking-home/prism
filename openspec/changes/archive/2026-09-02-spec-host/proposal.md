## Why

Проект Prism (сетевой медиа-плеер для умного дома) не имеет OpenSpec-спецификаций:
поведение системы задокументировано только в README и TODO.md, изменения
согласуются напрямую с пользователем без формального описания требований. Чтобы
дальнейшие изменения хоста (`Prism.Host`) можно было предлагать и ревьюить через
OpenSpec, нужна базовая спецификация, фиксирующая уже реализованное поведение.

## What Changes

- Задокументировать текущее поведение `Prism.Host` (сервер сканирования и
  раздачи видео) как baseline-спецификации: без изменения кода и без изменения
  поведения — только формализация того, что уже работает.
- Хост охватывает: каталог медиафайлов и информацию о сервере, выбор и доставку
  режима воспроизведения (прямая раздача / HLS-транскодирование), контентную
  идентификацию файлов (fingerprint, resolve, successor).

## Capabilities

### New Capabilities
- `host/media-catalog`: сканирование папок с видео (`Player:MediaDirectories`),
  `GET /api/info` (сведения о сервере: кодеки, ffmpeg, папки), `GET /api/media` и
  `GET /api/media/{id}` (список и карточка файла, `relativePath`, аудио/
  субтитровые дорожки, состояние `pending` до фоновой доразборки метаданных).
- `host/streaming`: выбор режима воспроизведения (`direct`/`hls`/`unsupported`)
  по кодеку и контейнеру; прямая раздача с HTTP Range (`GET /raw/{id}`); HLS
  master-плейлист с рендициями видео/аудио/субтитров, генерация сегментов
  сессиями ffmpeg (границы сессий, пейсинг чтения, вытеснение по LRU, уборка по
  простою); извлечение и раздача субтитров (`GET /api/media/{id}/subtitle/N.vtt`,
  сегментированный WebVTT в HLS); подхват аудио/субтитровых дорожек из соседних
  файлов по шаблонам (`Player:SubtitleFiles`/`Player:AudioFiles`).
- `host/content-identity`: контентный id файла (fingerprint по размеру и хешу
  краёв, персистентный кэш), `GET /api/resolve` (поиск записи по отпечатку —
  используется лаунчером), `GET /api/media/{id}/successor` (поиск, куда
  «переехало» содержимое, для ремапа на стороне библиотеки).

### Modified Capabilities
- (нет — в репозитории ещё нет ни одной спецификации)

## Impact

- Затронутый код: `Prism.Host` (ядро), `Prism.Host.Console`, `Prism.Host.Service`
  — только описание существующего поведения, изменений в коде эта задача не
  предполагает.
- Специфицируются только серверные контракты хоста; клиентские приложения
  (`Prism.Client`), библиотека (`Prism.Library`) и лаунчер (`Prism.Launcher`)
  описываются отдельными изменениями (`spec-launcher`, `spec-library`).
