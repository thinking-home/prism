## Purpose

Библиотека раздаёт собранный веб-клиент как статику со своего адреса, чтобы у
пользователя не было отдельного шага установки или настройки клиента, а сам
клиент по умолчанию обращался к той же библиотеке, с которой был открыт.

## ADDED Requirements

### Requirement: Раздача собранного веб-клиента
Библиотека SHALL раздавать статические файлы собранного веб-клиента из
сконфигурированной папки (по умолчанию `wwwroot` рядом с приложением). Если
папка отсутствует — раздача статики SHALL быть выключена, а HTTP API
библиотеки SHALL продолжать работать как обычно.

#### Scenario: Папка клиента присутствует
- **WHEN** сконфигурированная папка с собранным клиентом существует и содержит файлы
- **THEN** обращение к корню сервиса библиотеки отдаёт веб-клиент

#### Scenario: Папка клиента отсутствует
- **WHEN** сконфигурированная папка с клиентом не существует
- **THEN** раздача статики выключена, но эндпоинты `/api/...` библиотеки отвечают как обычно

### Requirement: Веб-клиент по умолчанию обращается к same-origin библиотеке
Настройка адреса библиотеки в веб-клиенте SHALL по умолчанию совпадать с
адресом, с которого клиент был загружен (same-origin), без необходимости
отдельно указывать URL библиотеки; настройка при этом SHALL оставаться
доступной для переопределения (например, для разработки).

#### Scenario: Клиент открыт с адреса библиотеки без явной настройки
- **WHEN** пользователь открывает адрес, с которого библиотека раздаёт клиент, не меняя настроек
- **THEN** клиент обращается к API той же библиотеки без дополнительной настройки адреса
