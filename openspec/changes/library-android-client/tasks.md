  `Prism.Player.Android`): `settings.gradle.kts`, корневой `build.gradle.kts`
  с версиями плагинов Android/Kotlin, модуль `app`.
- [x] 1.2 Настроить `app/build.gradle.kts`: `namespace`/`applicationId
  "org.prism.library"`, `minSdk 24`, `compileSdk`/`targetSdk` как у

- [x] 1.4 Иконка и подпись приложения (минимально — заглушка), чтобы

- [x] 1.5 Живая проверка: сборка, установка на телефон/эмулятор и на Android
