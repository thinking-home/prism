## Purpose

Обеспечивает управление интерфейсом приложения и пультом ТВ-приставки (фокус,
D-pad), и касанием на телефоне — единым интерфейсом без отдельных версий
экранов под каждый тип устройства.

## ADDED Requirements

### Requirement: Управление с пульта
Все интерактивные элементы экранов приложения (папки, файлы, действия,
шторка, настройки) SHALL быть доступны через фокус, управляемый D-pad пульта
ТВ-приставки — перемещение фокуса, подтверждение выбора и возврат назад — без
необходимости указывающего устройства.

#### Scenario: Навигация по списку папки пультом
- **WHEN** приложение запущено на ТВ-приставке, и пользователь перемещает
  фокус стрелками пульта по списку текущей папки
- **THEN** фокус видимо перемещается между элементами списка, и подтверждение
  (кнопка OK/Enter пульта) активирует выбранный элемент

#### Scenario: Возврат назад с пульта
- **WHEN** пользователь на экране, отличном от корня, нажимает кнопку
  «назад» пульта
- **THEN** приложение поднимается на уровень выше по текущей папке либо
  закрывает открытую шторку или диалог, если он был открыт

### Requirement: Работа на телефоне касанием
Те же экраны SHALL быть полностью управляемы касанием на телефоне, без
функциональности, доступной только с пульта.

#### Scenario: Навигация касанием
- **WHEN** приложение запущено на телефоне
- **THEN** пользователь может открывать папки, вызывать действия файла и
  работать со шторкой касанием, без пульта
