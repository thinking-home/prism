## Purpose

Даёт пользователю единственную необходимую настройку приложения — базовый URL
библиотеки Prism, к которой оно обращается.

## ADDED Requirements

### Requirement: Настройка адреса библиотеки
Приложение SHALL хранить единственную настройку — базовый URL библиотеки
Prism, к которой оно обращается за деревом, каталогом, плеерами и запуском
воспроизведения. Настройка SHALL быть доступна для изменения из интерфейса
приложения и сохраняться на устройстве между запусками.

#### Scenario: Первый запуск без настройки
- **WHEN** приложение запущено первый раз, и адрес библиотеки не задан
- **THEN** приложение предлагает пользователю ввести адрес библиотеки, прежде
  чем показывать содержимое папок

#### Scenario: Сохранение адреса между запусками
- **WHEN** пользователь задал адрес библиотеки и перезапустил приложение
- **THEN** приложение использует ранее сохранённый адрес без повторного ввода

#### Scenario: Смена адреса
- **WHEN** пользователь меняет адрес библиотеки в настройках
- **THEN** последующие запросы приложения идут по новому адресу
