## Purpose

Позволяет пользователю просматривать виртуальную структуру библиотеки как
текущую папку с переходом во вложенные группы и подъёмом наверх, без показа
полного дерева на экране — так интерфейс остаётся удобным и на телефоне, и на
ТВ-приставке.

## ADDED Requirements

### Requirement: Просмотр содержимого текущей папки
Приложение SHALL показывать содержимое текущего узла дерева библиотеки —
дочерние группы и файлы, состоящие непосредственно в этом узле, — используя
`GET /api/library/tree` (группы и членство) и `GET /api/media` (карточки
файлов, включая `present` и `playable`). Полное дерево библиотеки SHALL не
отображаться одновременно с текущей папкой.

#### Scenario: Открытие приложения показывает корень
- **WHEN** пользователь открывает приложение
- **THEN** показывается список групп верхнего уровня (без родителя) и файлов,
  не состоящих ни в одной группе

#### Scenario: Список группы содержит только её прямое содержимое
- **WHEN** пользователь заходит в группу, у которой есть и дочерние группы, и
  файлы, и в которой состоят также файлы её дочерних групп
- **THEN** список показывает дочерние группы и файлы этой группы, но не
  содержимое её дочерних групп

### Requirement: Порядок элементов в списке
Внутри списка текущей папки группы SHALL быть упорядочены по имени, файлы —
по имени (заголовку), группы и файлы не SHALL перемешиваться между собой (все
группы показываются одним блоком, все файлы — другим).

#### Scenario: Алфавитный порядок
- **WHEN** в текущей папке несколько групп и несколько файлов
- **THEN** группы в списке идут по алфавиту, и файлы в списке идут по алфавиту

### Requirement: Переход между папками
Приложение SHALL позволять зайти в дочернюю группу выбором её в текущем
списке и подняться в родительскую группу нажатием системной кнопки «назад» —
без отдельной кнопки или стрелки «наверх» в интерфейсе. В корне библиотеки
кнопка «назад» SHALL не подниматься по папке (обычное поведение системы,
например выход из приложения).

#### Scenario: Переход во вложенную группу
- **WHEN** пользователь выбирает группу в текущем списке
- **THEN** приложение показывает содержимое выбранной группы, она становится
  текущей папкой

#### Scenario: Подъём наверх
- **WHEN** пользователь, находясь в дочерней группе, нажимает системную
  кнопку «назад»
- **THEN** приложение показывает содержимое родительской группы

#### Scenario: В корне кнопка «назад» не поднимает по папке
- **WHEN** пользователь находится в корне библиотеки и нажимает системную
  кнопку «назад»
- **THEN** приложение не пытается подняться по папке (кнопка «назад» ведёт
  себя как обычно, например закрывает приложение)

### Requirement: Заголовок текущей папки
Приложение SHALL показывать в шапке экрана название текущей папки: имя группы
для вложенной папки, обозначение корня библиотеки — для корня.

#### Scenario: Заголовок корня
- **WHEN** пользователь находится в корне библиотеки
- **THEN** шапка экрана показывает, что это корень библиотеки

#### Scenario: Заголовок вложенной папки
- **WHEN** пользователь заходит в группу
- **THEN** шапка экрана показывает имя этой группы

### Requirement: Отображение недоступных файлов
Файл, отсутствующий на всех доступных хостах (`present:false`), SHALL
отображаться в списке текущей папки визуально отличимым от доступных файлов, а
не скрываться и не приводить к ошибке загрузки папки.

#### Scenario: Осиротевшая запись видна в списке
- **WHEN** в текущей папке есть файл с `present:false`
- **THEN** он показывается в списке с отметкой недоступности, а загрузка
  списка не завершается ошибкой

### Requirement: Пустая папка
Если у текущего узла нет ни дочерних групп, ни файлов — приложение SHALL
показывать состояние «папка пуста», а не ошибку.

#### Scenario: Пустая группа
- **WHEN** пользователь заходит в группу без дочерних групп и без файлов
- **THEN** приложение показывает, что папка пуста
