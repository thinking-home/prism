# Плеер для Android TV

**Prism.Player.Android** показывает видео на телевизоре или приставке с Android TV.
Он получает адрес фильма от координатора и открывает поток с хоста.
Во время просмотра можно пользоваться пультом.

Для выбора фильмов установите [Android-клиент библиотеки](./library-android)
или запускайте видео через [Launcher для Windows](./launcher).
Сам плеер не содержит каталога.

## Установка APK

Нужны устройство с **Android 7.0 или новее** и MQTT-брокер, доступный в домашней сети.

Перенесите подписанный APK плеера на устройство и откройте его для установки.
Если Android запросит разрешение, разрешите установку для используемого
файлового менеджера. При наличии настроенного ADB можно установить файл с компьютера:

```sh
adb install -r app-release.apk
```

Используйте **release-сборку** для домашних устройств. В debug-сборке у всех
плееров один идентификатор `emulator`, поэтому она не подходит для нескольких
телевизоров в одной сети.

## Сборка из исходников

Откройте папку `Prism.Player.Android` в Android Studio.
Установите Android SDK 36 и настройте JDK для Gradle.
Создайте ключ подписи и укажите его параметры в `keystore.properties`
в корне Android-проекта:

```properties
storeFile=prism-release.jks
storePassword=ваш_пароль_хранилища
keyAlias=ваш_псевдоним_ключа
keyPassword=ваш_пароль_ключа
```

Поместите файл ключа по указанному пути. Сохраните его для будущих обновлений:
подпись новой версии должна совпадать с установленной.

В терминале из папки Android-проекта выполните:

```sh
./gradlew assembleRelease
```

В Windows используйте `gradlew.bat assembleRelease`.
APK появится в `app/build/outputs/apk/release/app-release.apk`.

## После установки

Откройте настройки плеера, задайте понятное имя, например «Гостиная»,
и адрес MQTT-брокера. При необходимости укажите логин и пароль.

Чтобы плеер мог выводить видео по входящей команде из фона, разрешите показ
поверх других приложений и отключите для него оптимизацию батареи.
Соответствующие настройки описаны в
[руководстве плеера](https://github.com/thinking-home/prism/blob/library-android-client/Prism.Player.Android/README.md).

Подключите библиотеку или Launcher к тому же брокеру. Плеер станет доступен
для выбора при запуске фильма.

## Настройки приложения

Откройте «Настройки» на главном экране плеера. Значения сохраняются на устройстве.

| Поле | Что указать |
| --- | --- |
| Адрес MQTT-брокера | Полный адрес с протоколом и портом, например `tcp://192.168.1.10:1883` |
| Имя пользователя | Логин брокера; оставьте пустым, если брокер допускает анонимный вход |
| Пароль | Пароль для указанного логина |
| Имя плеера | Понятное название, например «Гостиная» или «Спальня» |
| Идентификатор плеера | Только для чтения: создаётся автоматически и отличает устройство от остальных |

Нажмите «Сохранить»: плеер переподключится к брокеру с новыми настройками.
Статус MQTT на главном экране показывает, удалось ли подключение.
В release-сборке адрес изначально пуст — его нужно заполнить.

Адрес хоста или библиотеки вводить не требуется: плеер получает адрес видео
в команде запуска. Не используйте `localhost` для брокера на другом устройстве.

Разрешение показа поверх других приложений и исключение из оптимизации батареи
задаются в системных настройках Android, отдельно от этих полей.
