# Компоненты

Выберите компоненты под свой способ просмотра. Хост предоставляет видео, плеер
показывает его на телевизоре, а библиотека объединяет коллекцию и координирует запуск.

| Компонент | Для чего нужен | Варианты установки |
| --- | --- | --- |
| [Хост](./host) | Доступ к видеофайлам в домашней сети | MSI для Windows или запуск из исходников |
| [Плеер для Android TV](./player-android) | Просмотр на телевизоре | Установка APK или сборка из исходников |
| [Библиотека](./library) | Общий каталог, просмотр в браузере и запуск на плеерах | Запуск из исходников |
| [Android-клиент библиотеки](./library-android) | Выбор фильма и экрана с телефона или телевизора | Установка APK или сборка из исходников |
| [Launcher для Windows](./launcher) | Отправка видео из проводника на телевизор | Вместе с хостом или запуск из исходников |

## Что установить

**Для просмотра в браузере** нужны хост и библиотека. Веб-интерфейс устанавливается
вместе с библиотекой по инструкции на её странице.

**Для выбора фильмов на телефоне или телевизоре** добавьте Android-клиент
библиотеки и плеер для Android TV. Оба Android-компонента можно установить на
одну приставку.

**Для запуска из проводника Windows** нужны хост, Launcher и плеер для Android TV.
Библиотека в этом сценарии необязательна.

Для команд телевизионным плеерам нужен MQTT-брокер в домашней сети. Укажите один
и тот же брокер в настройках плееров и компонентов, которые запускают видео.
Для просмотра в браузере MQTT не требуется.

## Перед установкой

Все устройства должны иметь доступ друг к другу по домашней сети. В настройках
используйте сетевые адреса компьютеров, например `192.168.1.10`.
Адрес `localhost` означает устройство, на котором он используется: телевизор
не сможет по нему подключиться к серверу.

Инструкции по сборке выполняются из исходников Prism. Android-клиент библиотеки
есть в ветке `library-android-client`; используйте версию репозитория, содержащую
папки нужных компонентов. Ссылки на исходники приведены на их страницах.
