# Android-клиент библиотеки

**Prism.Library.Android** позволяет просматривать коллекцию по группам,
открывать сведения о фильмах и запускать их на выбранном плеере.
На телефоне интерфейс управляется касаниями, на Android TV — пультом.

Клиент и [плеер](./player-android) можно установить на одну приставку:
в одном вы выбираете фильм, другой его показывает.

## Установка APK

Нужны **Android 7.0 или новее** и запущенный [сервис библиотеки](./library).
Перенесите APK клиента на телефон, телевизор или приставку и откройте его.
При запросе Android разрешите установку для используемого файлового менеджера.

Если настроен ADB, APK можно установить с компьютера:

```sh
adb install -r app-debug.apk
```

Имя файла в примере соответствует сборке для проверки, описанной ниже.

## Сборка из исходников

Код находится в папке `Prism.Library.Android`
[ветки library-android-client](https://github.com/thinking-home/prism/tree/library-android-client/Prism.Library.Android).

Откройте эту папку в Android Studio, установите Android SDK 36 и настройте JDK
для Gradle. Для сборки APK выполните из папки проекта:

```sh
./gradlew assembleDebug
```

В Windows используйте `gradlew.bat assembleDebug`.
Результат: `app/build/outputs/apk/debug/app-debug.apk`.

Для подписанной release-сборки используйте мастер
**Build → Generate Signed App Bundle / APK** в Android Studio и выберите APK.
Сохраняйте ключ подписи, чтобы устанавливать обновления поверх предыдущей версии.

## После установки

1. Откройте настройки клиента.
2. Введите адрес библиотеки, например `http://192.168.1.10:8081`.
3. Откройте группу, выберите фильм и действие запуска на плеере.
4. Выберите телевизор из списка.

Для запуска на телевизоре библиотека и плеер должны быть подключены к одному
MQTT-брокеру. В самом Android-клиенте достаточно указать адрес библиотеки.

## Настройки приложения

У клиента одна настройка — **адрес библиотеки**. При первом запуске экран
настройки открывается автоматически. Позже его можно открыть кнопкой-шестерёнкой.

Укажите полный адрес сервиса, например `http://192.168.1.10:8081`,
и нажмите «Сохранить». Приложение откроет каталог и запомнит адрес для следующих
запусков. Пустое значение сохранить нельзя.

Используйте адрес библиотеки, а не хоста: по умолчанию библиотека работает на
порту `8081`, хост — на `8080`. Адрес должен быть доступен с телефона или
телевизора; `localhost` указывает на само Android-устройство.

MQTT-брокер, логин и пароль в этом клиенте не настраиваются: подключение к
плеерам выполняет сервис библиотеки. Если каталог открывается, а запустить
фильм на телевизоре не получается, проверьте MQTT в настройках библиотеки
и плеера.
