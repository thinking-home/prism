# Launcher для Windows

**Prism.Launcher** отправляет видео из проводника Windows на выбранный плеер.
Он работает с локальным хостом и MQTT-брокером; сервис библиотеки не требуется.

## Установка вместе с хостом

Launcher входит в [MSI-установщик хоста](./host).
Он устанавливается в `C:\Program Files\Prism Host\launcher` и запускается
при входе в Windows. Для работы нужен **.NET Desktop Runtime 10**, версия x64.

После первого запуска появятся значок в области уведомлений и пункт
**«Отправить → Prism»** в контекстном меню файлов.

## Запуск из исходников

В Windows с установленным **.NET 10 SDK** выполните из корня репозитория:

```powershell
dotnet run --project Prism.Launcher
```

Перед запуском настройте `Prism.Launcher/appsettings.json`.
При установке через MSI этот файл находится в папке `launcher` рядом с программой.

## Настройка

Укажите адрес локального хоста, доступный телевизору по сети, и адрес MQTT-брокера:

```json
{
  "Host": {
    "Address": "192.168.1.20",
    "Port": 8080
  },
  "Broker": {
    "Address": "192.168.1.10",
    "Port": 1883,
    "User": "",
    "Password": ""
  }
}
```

Здесь `192.168.1.20` — компьютер с хостом и Launcher,
а `192.168.1.10` — компьютер с брокером. Они могут быть одним устройством.
После изменения настроек перезапустите Launcher.

## Как включить фильм

Убедитесь, что файл находится в одной из папок, которые обслуживает хост.
В проводнике нажмите на файл правой кнопкой мыши, выберите
**«Отправить → Prism»**, затем нужный плеер.
В Windows 11 меню «Отправить» может находиться в разделе «Показать дополнительные параметры».

Для появления телевизора в списке установите на него
[плеер для Android TV](./player-android) и подключите к тому же MQTT-брокеру.

[Исходный код Launcher](https://github.com/thinking-home/prism/tree/library-android-client/Prism.Launcher)

## Поля конфигурации

Файл `appsettings.json` — JSON с секциями `Host` и `Broker`.
Launcher читает его при запуске; редактора настроек в интерфейсе нет.

| Параметр | Значение при отсутствии поля | Назначение |
| --- | --- | --- |
| `Host:Address` | Пустая строка | IP или имя компьютера с хостом, без `http://` и порта |
| `Host:Port` | `8080` | HTTP-порт хоста |
| `Broker:Address` | Пустая строка | IP или имя MQTT-брокера, без протокола и порта |
| `Broker:Port` | `1883` | MQTT-порт |
| `Broker:User` | Пустая строка | Логин брокера, если требуется |
| `Broker:Password` | Пустая строка | Пароль брокера |

В поставляемом файле оба адреса заданы как `localhost`. Замените адрес хоста
на сетевой: он используется и при передаче команды телевизору.
Пустой адрес брокера отключает подключение к MQTT.
